TopicWise Quiz Generator

Lets students take topic-based quizzes and track scores. An admin interface generates quiz links and shows the leaderboard.

FocusWeb App · Topic-Based Quizzes

The Problem

Running a topic-specific quiz involves choosing questions, distributing access, and collecting scores.

The Approach

  • Offer topic-based quizzes from a question bank.
  • Provide sign-in and submit scores through the Spring Boot API.
  • Let admins generate quiz links and view the student leaderboard.

Architecture

An HTML, CSS, and JavaScript frontend calls Spring Boot REST controllers for authentication, quizzes, and admin operations. The backend keeps question selection, score handling, and link generation in separate services.
