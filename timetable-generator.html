Case Study · 01

Advanced Timetable Generator & Conflict Resolver

Generates college timetables, flags scheduling conflicts, and supports local repairs when classes need to move.

FocusScheduling · Constraint Satisfaction

The Problem

College schedules have to fit classes into available rooms and time slots without double-booking teachers, rooms, or student groups.

The Approach

  • Generate schedules with a C++ constraint solver that uses backtracking and greedy heuristics.
  • Review conflicts, make manual edits, and try localized rescheduling without regenerating the entire timetable.
  • Explore schedules by section, faculty, or room, inspect workload analytics, and export a PDF.

Architecture

The Python and Streamlit interfaces send JSON requests to a C++ backend. The scheduler, conflict detector, and rescheduler run in the backend. The dashboard turns the returned assignments into timetable views and reports.

PythonC++StreamlitBacktrackingGreedy heuristics

Running the Project

Difficult move requests can reach the configured timeout. The editor surfaces the failure so the operator can choose a different slot or adjust the timeout.
