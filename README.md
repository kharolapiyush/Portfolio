## Overview

A personal developer portfolio showcasing Piyush Kharola's journey in software development, iOS training, academic background, technical skills, certifications, and personal projects.

Built using vanilla web technologies without external frameworks or build dependencies.

## Features

- Dedicated project case studies
- Education and professional training
- Technical skills and certifications
- Dynamic GitHub repository count
- GitHub contribution calendar
- Graceful fallback when external APIs are unavailable
- Lightweight architecture with no build dependencies

## Tech Stack

- **HTML5** — Website structure
- **CSS3** — Styling and visual design
- **JavaScript** — Interactivity and API integration
- **GitHub API** — Public repository statistics
- **GitHub Contributions API** — Contribution calendar by J. Gruber

## Getting Started

Run the following command from the repository root:

```bash
python -m http.server 8000
```

Open the following URL in your browser:

```text
http://localhost:8000
```

No package installation or build process is required.
